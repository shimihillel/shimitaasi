# שימי, תעשי — V29

עיצוב לילך, חמאה ומנטה בהשראת הרפרנסים שנבחרו: כרטיסי משימות מובחנים,
קווי מתאר עדינים, הדגשת עדיפות, ופס התקדמות קומפקטי.

## פס ההתקדמות

מציג בוצעו X מתוך Y, ובקניות נקנו X מתוך Y. הספירה מתבססת על הפריטים
המוצגים ברשימה הנוכחית, כולל פריטים שבוצעו גם אם אזור הביצוע מקופל.
משימות עתידיות שאינן מוצגות וטווחי תאריכים ללא סימון ביצוע אינם נספרים.
רשימה ריקה מציגה 0 מתוך 0 ופס ריק; השלמת כל הפריטים מציגה פס מלא.
הוספה, מחיקה, דחייה, ביטול ביצוע, שחזור וניקוי הרשימה משנים את המכנה בהתאם.
זהו מצב הרשימה הנוכחית, ולא סטטיסטיקת השלמות היסטורית.

`progress.js` הוא רכיב תצוגה שקורא את מצב האפליקציה וצופה ברענון הרשימה.
הוא אינו משנה משימות, מפתחות אחסון, פונקציות מקוריות או פורמט גיבוי.
`app.js` ו־`calendar-swipe.js` זהים בבתים למקור V27.1.
הניסוחים והפיצ׳רים המקוריים נשמרו.

## קבצים והתקנה

כל הקבצים בתיקייה נחוצים, כולל שכבות CSS, progress.js, fonts והאייקונים.
הגופן מקומי וברישיון OFL שבתיקיית fonts; אין תלות בשירות גופנים חיצוני.

לפני עדכון האתר הקיים, להוריד גיבוי מתוך האפליקציה. להעלות את **תוכן התיקייה**
לאותה כתובת קיימת, בלי למחוק נתוני אתר. תצוגה מקומית בכתובת אחרת לא מציגה
אוטומטית את המשימות מהאתר הקיים; אפשר לייבא אליה גיבוי.
הגרסה הזו לא פורסמה ולא החליפה את האתר הקיים.

## אימות

23 בדיקות הפעולות הקיימות עברו ב־Chrome, כולל קניות, משימות קבועות,
תזמון, כוכבים, סידור, ביצוע והחזרה, הורדת גיבוי JSON, שחזור ושמירה לאחר רענון.
נבדקו רוחבי 320, 375, 390, 430, 768 ו־1280 ללא גלישה אופקית.
פס ההתקדמות נבדק ברשימה ריקה, הוספה, ביצוע, החזרה, סינון עתידיות וטווחים,
מעבר לקניות, השלמה מלאה וניקוי הפריטים שבוצעו.
הבדיקות השתמשו בנתוני דוגמה בפרופיל דפדפן נפרד. לא בוצעה בדיקת אייפון פיזי או Safari.

## האייקון החדש

האייקון המאושר שולב בהפניות מסך הבית ובמניפסט. קובצי icon-v29 כוללים מקור גדול וגדלי 32, 180, 192 ו־512 פיקסלים. שמות חדשים מסייעים לרענון המטמון.
האייקון נוצר בכלי יצירת התמונות המובנה: פתק חמאה עם וי כהה וניצוץ מנטה על רקע לילך אטום, בסגנון האפליקציה.
