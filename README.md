# שימי, תעשי — V27 · Soft Premium

רענון עיצובי המבוסס על V26.6, בכיוון הראשון שנבחר. זו גרסת עיצוב, לא מעבר למערכת נתונים חדשה.

## מה השתנה

שמנת חמה ופסטלים רכים, טיפוגרפיה קלה יותר וקווים עדינים. הפאנל העליון מכווץ לפעולות מסודרות עם אייקונים; הטאבים לעשות/לקנות קיבלו שפה אחידה. פתקי עכשיו קורה, על הראש ולקנות דחוף מובחנים בצבע בלי לשנות את התוכן שלהם. כותרות המטלות מקבלות יותר רוחב, הפעולות מאורגנות בשורה משנית, וברשימת הקניות נשמרת תצוגה קצרה בלי תאריכים.

היומן, רשימת העתידיות, הקבועות, הגיבוי ופופאפי ההוספה/עריכה קיבלו אותו עיצוב. חיווי היום נשאר ורוד; היום הנבחר שומר על המסגרת הזהובה. טווחי תאריכים משתמשים בלילך, עם מסגרת היום מעליהם. לא נוספו מסכים, התראות, חשבונות, קטגוריות או פילטרים חדשים.

## עדכון הגרסה

1. לפני העדכון: לפתוח את האפליקציה הנוכחית ולשמור קובץ דרך **גיבוי → להוריד גיבוי**.
2. לחלץ את ה־ZIP. להעלות את **התוכן שבתיקייה** לאותו מקום שממנו מתפרסמת האפליקציה ב־GitHub Pages. לא ליצור אתר חדש ולא לשנות את הכתובת.
3. להעלות גם את הקובץ החדש `premium.css`, יחד עם `index.html`, `style.css`, `app.js`, `manifest.json` ותיקיית `icons`.
4. אחרי שהפרסום הסתיים, לסגור ולפתוח שוב את האפליקציה. הנתונים אמורים להישאר באותו דפדפן/אתר. אין צורך למחוק את האפליקציה או לנקות נתוני אתר; ניקוי נתוני אתר עלול למחוק את השמירה המקומית.

## מה נשמר

`app.js` זהה לחלוטין לקובץ שב־V26.6 שנשלח: אותם מפתחות localStorage, אותו מבנה גיבוי, ואותה לוגיקה של מטלות, קניות, קבועות, עתידיות, טווחים, מחר, כוכב וביצוע/החזרה. קוד הבדיקות ונתוני ההדגמה אינם כלולים באפליקציה.

העיצוב מרוכז בקובץ `premium.css`, שנטען אחרי העיצוב הקיים. לא נוספו ספריות, פונטים להורדה, שירותים חיצוניים או service worker חדש. שם האפליקציה והאייקון הקיימים נשארו.

## בדיקות ומגבלות

בוצעו בדיקות אוטומטיות בסביבת Chromium מבודדת: הוספה, עריכה, הזזה, כוכב, מחר, השלמה והחזרה, קניות בכמה שורות, הוספה ועריכה מהיומן, טווחים ומחיקתם, קבועות, והמרת נתונים לגיבוי ושחזור. נבדקה התאמת רוחב המסכים ב־320, 375, 390, 430 ו־1366 פיקסלים.

הבדיקות השתמשו בנתוני דמה ובתחליף localStorage בזיכרון; הן אינן בדיקת שמירה, התקנה או הורדה על טלפון אמיתי. לא בוצעה בדיקה באייפון, ב־Safari או באתר GitHub Pages שלך. לפני שמחליפים את הגרסה, יש לשמור גיבוי.
