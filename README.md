# שימי, תעשי — V27.1

עדכון קטן על בסיס V27 Soft Premium.

## מה השתנה

- הרווחים האנכיים ברשימות המטלות והקניות צומצמו. אזורי הלחיצה על הסימון, הכוכב, החצים ו״מחר״ נשארו לפחות 44×44 פיקסלים. שורות עם טקסט ארוך או תגיות יכולות לגדול לפי התוכן; אין הגבלת גובה שמסתירה אותן.
- הכפתור ״עתידיות״ וכותרת החלון נקראים עכשיו **יומן**. אפשר עדיין לעבור בין יומן לרשימה.
- במסך היומן ניתן להחליק על **רשת הימים עצמה**: ימינה לחודש הבא, שמאלה לחודש הקודם, בהתאם לכיוון העברי. בכל החלקה מתבצע מעבר של חודש אחד. החצים וכפתור ״היום״ נשארו.
- החלקה אנכית מיועדת לגלילה, לא להחלפת חודש. תנועה קצרה מדי אינה מחליפה חודש. שתי אצבעות מבטלות את מחוות החלפת החודש, כדי לאפשר זום רגיל.

## איך מעדכנים

1. לשמור גיבוי מתוך האפליקציה הקיימת.
2. לחלץ את ה־ZIP ולהעלות את **התוכן שבתיקייה** לאותו מיקום בגיטהאב שבו האפליקציה כבר מתפרסמת. להחליף את הקבצים הקיימים ולהעלות גם את `calendar-swipe.js` החדש.
3. יש לכלול את `index.html`, `style.css`, `premium.css`, `app.js`, `calendar-swipe.js`, `manifest.json` ותיקיית `icons`.
4. אחרי שהעדכון התפרסם, לסגור ולפתוח את האפליקציה. אין צורך למחוק את האפליקציה או לנקות נתוני אתר.

לא לשנות את כתובת האתר או את מפתחות האחסון. קובץ `app.js` זהה בבתים לקובץ של V27; שמות מפתחות השמירה ופורמט הגיבוי לא הוחלפו. התוספת בקובץ `calendar-swipe.js` מפעילה את אותם כפתורי חודש שכבר קיימים ואינה קוראת או משנה מידע שמור.

## בדיקות ומגבלות

בוצעו בדיקות דפדפן ב־Chromium ברוחבי 320, 375, 390, 430 ו־768 פיקסלים: גודל כפתורי פעולה, התאמת רוחב ושהתוכן נשאר בתוך שורת המטלה. נבדקו מחוות מגע מדומות ברמת הדפדפן: החלקה לשני הכיוונים, תנועה קצרה, גלילה אנכית, ביטול מחווה עם אצבע נוספת, לחיצה על יום, מעבר שנה וחזרה להיום. נבדקו גם פעולות הוספה מתוך היומן, עריכה ושמירה, כוכב, שינוי סדר, ביצוע והחזרה, ״מחר״ וקניות.

הבדיקות רצו בסביבת בדיקה מבודדת עם אחסון בזיכרון ונתוני דמה. הן אינן בדיקת localStorage אמיתי, התקנה, אתר GitHub Pages או אייפון/Safari. ייצוא גיבוי נבדק ברמת תוכן JSON, לא כהורדה על טלפון. קוד הבדיקות ונתוני הדמה אינם כלולים בגרסה.

הערה על התנהגות קיימת: אחרי עריכת הטקסט מתוך היומן, תוכן כרטיס היום עשוי להתעדכן רק לאחר בחירה חוזרת ביום; נתון המטלה עצמו נשמר. העדכון הזה אינו משנה את מנגנון העריכה הקיים.
